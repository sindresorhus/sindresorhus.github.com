Write a short note and see it as a sticky note on your Home Screen, Lock Screen, StandBy, or desktop.

The app is simple by design.

**Features**

- Each widget is its own note, so you can add a widget for each thing to remember. Tap a widget to write or change its note
- Choose the background color (7 colors), the font (10 fonts), and the text alignment when you edit the widget

For macOS, it’s only available for Apple silicon Macs running macOS 26 or later.

## Frequently Asked Questions {#faq}

### How do I add the widget? {#how-do-i-add-the-widget}

- [iOS](https://support.apple.com/118610)
- [macOS](https://support.apple.com/guide/mac-help/mchl52be5da5/mac)

### Can you add more features and settings? {#can-you-add-more-features-and-settings}

I’m happy to consider it, but I also want to keep the app simple. Check out my [Any Text app](/any-text), which has a lot more features.

### Can you add a text size setting? {#can-you-add-a-text-size-setting}

The text size is large for short text but scales down to make the text fit. I don’t want to complicate it with a text size setting. If you really need it, check out [Any Text](/any-text).

### Can you add a text color setting? {#can-you-add-a-text-color-setting}

Same answer as the above.

### Can I edit text directly in the widget? {#can-i-edit-text-directly-in-the-widget}

No. A widget cannot have a text field. This is a macOS/iOS limitation. Tap the widget instead, and the app opens that note, ready to edit.

### How is this different from the built-in Stickies app on macOS? {#stickies}

The Stickies app is a normal app and has to either float on top of everything or it has to be manually brought to the front when needed. Memo Widget always lives on your desktop or in the Notification Center, just a [gesture away](https://www.howtogeek.com/678073/how-to-quickly-show-your-desktop-on-mac/). The Stickies app also takes up space in your Dock. The Stickies app supports formatting, while Memo Widget keeps it simple with just plain text.

### Can you add actions for Shortcuts? {#can-you-add-actions-for-shortcuts}

I don’t plan to add this. Check out my [Any Text app](/any-text), which has this.

### How is this different from your Any Text app? {#how-is-this-different-from-your-any-text-app}

[Any Text](/any-text) has a lot of features and is very flexible. With this app, I wanted to make something simple and focused.
