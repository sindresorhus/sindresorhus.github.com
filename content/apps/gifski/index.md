Turn a video into a GIF that still looks like the video. Gifski uses thousands of colors per frame, so gradients stay smooth instead of turning into bands.

It’s a macOS app for the [gifski encoder](https://gif.ski), which uses [pngquant’s](https://pngquant.org) fancy features for efficient cross-frame palettes and temporal dithering.

**Features**

- Trim and crop the video, and set the exact dimensions
- Change the speed and the frame rate, up to 50 FPS
- Loop the GIF, bounce it back and forth, or add a delay between the loops
- See a preview before you convert
- Make smaller GIFs with the quality slider
- Convert from the Share menu, the Services menu, or the Shortcuts app

It converts the video formats that macOS supports, like MP4 and MOV with H.264, HEVC, or ProRes.

If you don’t have a video, you can try the app out with [this one](https://github.com/sindresorhus/meta/assets/170270/6606c1d2-c0ce-4b7e-9eb8-a3916e601e48).
