# Tiny Apps

Tiny but useful macOS utilities. These are generally not up to the quality of my [main apps](/apps).

@TinyApp(title: "Services Debug", icon: "/apps/services-debug/icon.png", download: "https://www.dropbox.com/scl/fi/c2741txqdrma549ohp743/Services-Debug-1.2.0-1761031297.zip?rlkey=0b67gsrkcl7ef176fbfxyz8bx&raw=1", macOS: "15.4") {
Check what content an app provides to services in the “Services” menu.

This can be useful when developing support for [system services](https://support.apple.com/guide/mac-help/use-services-in-apps-mchlp1012/mac) in your macOS app.
}

@TinyApp(title: "Copy URL", icon: "/apps/copy-url/icon.png", download: "https://github.com/sindresorhus/Copy-URL/releases/latest/download/Copy.URL.zip", source: "https://github.com/sindresorhus/Copy-URL", macOS: "13.5") {
Adds copy functionality to browser picker apps.

Choose it as the browser in [Velja](/velja), or another browser picker, and the link is copied instead of opened.
}

@TinyApp(title: "Safari Private", icon: "/apps/safari-private/icon.png", download: "https://github.com/sindresorhus/Safari-Private/releases/latest/download/Safari.Private.zip", source: "https://github.com/sindresorhus/Safari-Private", macOS: "13.5") {
Open the given URL in a private Safari window.

Choose it in [Velja](/velja), or another browser picker, to open a link in a private Safari window.
}
