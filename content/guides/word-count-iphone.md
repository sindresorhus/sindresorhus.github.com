@QuickAnswer {
	Write or paste the text in [Plain Text Editor](/plain-text-editor). It shows the number of words and characters at the bottom of the screen while you type, like “120 words • 640 characters”. [Without an app](#without-an-app), paste the text in Pages, the word processor of Apple, and turn on “Show Word Count”.
}

## With Plain Text Editor

@Steps {
1. Open [Plain Text Editor](/plain-text-editor), and tap “Create Document”.
1. Write the text, or paste it, like from a note in the Notes app.
1. Look at the count at the bottom of the screen.
}

The numbers change while you type. When you select a part of the text, they count only the selection.

@Tips {
- To also count the lines, or to show only one of the numbers, tap the “…” button, tap “Settings”, and choose the counts in “Stats”. When the bar shows only the words or only the characters, tap the count to switch between them.
- The text is a plain text file in the Files app. [How to create a text file on iPhone.](guide:create-text-file-iphone)
- On Mac, Plain Text Editor shows the count too. [How to see the word count on Mac.](guide:word-count-textedit-mac)
}

## Without an app

Pages, the word processor of Apple, has a word count ([Apple’s instructions](https://support.apple.com/guide/pages-iphone/tand47165437/ios)):

@Steps {
1. Paste the text in a new document in Pages.
1. On iPhone, tap the More button at the top of the screen, tap “View Options”, and tap “Show Word Count”. On iPad, tap the View Options button, and tap “Show Word Count”.
1. To see the characters, the paragraphs, or the pages, tap the count at the bottom of the screen.
}

Like in Plain Text Editor, the count is only for the selection when you select text. Pages is a large app for documents with a layout, so it is slow for a quick count.

In the Shortcuts app, the “Count” action can count the words of a text, like the text on the clipboard with “Get Clipboard” before it.
