@QuickAnswer {
	Select the file in Finder, and press ++Option+Command+C++. Or right-click the file, hold ++Option++, and choose “Copy … as Pathname”. To have a “Copy Path” item in the right-click menu without the ++Option++ key, use [Supercharge](../apps/supercharge/index.md).
}

## With Supercharge

@Steps {
1. Open the settings of [Supercharge](../apps/supercharge/index.md), click “Tweaks”, and click “Configure…” next to “Context menu items”.
1. In the “Main Menu” tab, turn on “Copy Path”. You can also turn on “Copy Filename”, “Copy File URL”, and “Copy Markdown Link”.
1. Right-click a file or folder in Finder, and choose “Copy Path”. To copy the path of the open folder, right-click an empty area of the window.
}

When you select many files, “Copy Paths” copies one path per line.

The right-click items cannot show in synced folders, like iCloud Drive and Dropbox, and also not in Desktop and Documents when they sync with iCloud. There, right-click the file, and choose “Services › Copy Path”.

## Without an app

@Steps {
1. Select the file or folder in Finder.
1. Press ++Option+Command+C++. Or right-click it, hold ++Option++, and choose “Copy “name” as Pathname”, which replaces “Copy”.
}

You can also drag a file into a Terminal window to type its path. The built-in way works well when you remember the ++Option++ key. Supercharge shows the item every time, and adds other formats, like a file URL.
