@QuickAnswer {
	macOS does not delete old screenshots. They stay on the desktop, or in the folder you chose, until you delete them. [Supercharge](../apps/supercharge/index.md) moves the screenshots that have been in the folder for more than 30 days, or the number of days you choose, to another folder.
}

## With Supercharge

@Steps {
1. Open the settings of [Supercharge](../apps/supercharge/index.md), and click “Tweaks”.
1. In the “Screenshots” section, find “Move screenshots added more than 30 days ago to (beta)”.
1. Click “Choose…”, and choose a folder, like a new folder named “Old Screenshots”.
1. To change the number of days, click the arrows next to “30 days”.
}

It uses the date when the screenshot came into the folder, not when it was taken. To keep a screenshot, give it the tag “Supercharge Ignore”. It moves the screenshots, and does not delete them, so delete the files in that folder when you no longer need them. To turn it off, clear the folder.

If you use another screenshot app, set the screenshot tool of macOS to save to the same folder, so Supercharge also moves those screenshots.

## Without an app

- **Delete by hand:** Select the old screenshots in Finder, and press ++Command+⌫++ to move them to the Trash. Sort the folder by “Date Added” to find the old ones.
- **Save to another folder:** Press ++Shift+Command+5++, click “Options”, and choose a folder below “Save to”. The desktop stays clean, but the folder still grows.

[Apple’s instructions.](https://support.apple.com/guide/mac-help/take-screenshots-mh26782/mac) Supercharge is for when you take many screenshots and only need the new ones.
