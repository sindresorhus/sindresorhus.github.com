@QuickAnswer {
	In a Finder window in column view, choose “View › Show View Options”, and select “Resize columns to fit filenames”. Each column then gets the width of its longest name. To fit the columns only when you want, set a keyboard shortcut for it in [Supercharge](/supercharge).
}

## With Supercharge

@Steps {
1. Open the settings of [Supercharge](/supercharge), and click “Tweaks”.
1. In the “Finder” section, find “Manually adjust column widths to filenames in “Columns” view”, and choose one of the shortcuts, like ++Control+A++.
1. In a Finder window in column view, press the shortcut. All the columns get the width of their longest name.
}

If the menu of the shortcuts is dimmed, the automatic way is on: turn off “Auto‑adjust column widths to filenames in “Columns” view” in Supercharge, or “Resize columns to fit filenames” in Finder.

This is for when you like to set the widths yourself, and fit them only now and then. For the automatic way, use the setting of Finder below. Supercharge has the automatic way too, in the same section.

## Without an app

Finder can fit the columns by itself:

@Steps {
1. Open a Finder window, and choose “View › as Columns”.
1. Choose “View › Show View Options”.
1. Select “Resize columns to fit filenames”.
}

This is free, and it is all that most people need. To fit one column one time, double-click the small handle at the bottom of the line to the right of the column. Right-click the handle for “Right Size All Columns Individually”.

A column can still be a little too narrow in a folder that syncs, like iCloud Drive, as the status icons take space, and in a narrow window.
