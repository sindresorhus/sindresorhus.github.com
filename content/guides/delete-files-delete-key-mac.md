@QuickAnswer {
	Select the file in Finder, and press ++Command+⌫++ to move it to the Trash. The ++⌫++ key alone does nothing in Finder. To delete with only ++⌫++, like on Windows, use [Supercharge](../apps/supercharge/index.md).
}

## With Supercharge

@Steps {
1. Open the settings of [Supercharge](../apps/supercharge/index.md), and click “Tweaks”.
1. In the “Finder” section, turn on “Move files to Trash with ⌫ (Delete) instead of ++Command+⌫++”.
1. Select a file in Finder, and press ++⌫++. The file moves to the Trash.
}

It also works with the Backspace key of external keyboards. It cannot be on together with the Supercharge setting that goes back to the previous folder with ++⌫++.

## Without an app

- **Move to the Trash:** Select the files, and press ++Command+⌫++, or choose “File › Move to Trash”. You can also drag them to the Trash in the Dock.
- **Delete at once:** Press ++Option+Command+⌫++. The files do not go to the Trash, so you cannot get them back.

[Apple’s keyboard shortcuts.](https://support.apple.com/102650) ++Command+⌫++ is easy to learn, and it protects you from deleting a file by accident. Supercharge is for when your fingers expect ++⌫++, like when you also use Windows.
