@QuickAnswer {
	Press ++Command+▲++ in Finder to go to the folder that contains the current folder, also when you did not come from it. To go up with only one key, turn on “Finder: Go to enclosing folder with Esc” in [Supercharge](/supercharge).
}

## With Supercharge

@Steps {
1. Open [Supercharge](/supercharge), and give it the access that it asks for in [“Device Control and Data Access”](/apps/faq#device-control-access).
1. Open the Supercharge settings, and click “Tweaks”.
1. In the “Experimental” section, turn on “Finder: Go to enclosing folder with Esc”.
1. Press ++Esc++ in a Finder window. Finder goes up one folder.
}

++Esc++ still closes Quick Look, and stops a rename, a search, or a drag. To go back to the folder that you came from, like with the back button, see [how to go back with the Delete key](guide:backspace-go-back-mac).

## Without an app

- **Keyboard:** Press ++Command+▲++. To open the folder above in a new window, press ++Control+Command+▲++. <source:https://support.apple.com/102650>
- **Menu bar:** Choose “Go › Enclosing Folder”.
- **Path bar:** Choose “View › Show Path Bar”. The bottom of the window then shows all the folders above the current folder: double-click one to go to it.
- **Title:** Hold ++Command++ while you click the name of the folder at the top of the window, and choose a folder in the menu.

Up is not the same as back: ++Command+[++ goes to the folder that you saw before, which is not always the one above.
