@QuickAnswer {
	macOS has no keyboard shortcut to start the screen saver. It can start it when you move the pointer into a corner of the screen. With [Supercharge](../apps/supercharge/index.md), you can set a keyboard shortcut for it.
}

## With Supercharge

@Steps {
1. Open the settings of [Supercharge](../apps/supercharge/index.md), and click “Shortcuts”.
1. Click the field next to “Start screen saver”, and press the keyboard shortcut that you want.
1. Press the shortcut. The screen saver of macOS starts.
}

Supercharge starts the screen saver that you chose in System Settings.

## Without an app

- **Hot corner:** In “[System Settings › Desktop & Dock](x-apple.systempreferences:com.apple.Desktop-Settings.extension)”, click “Hot Corners…”, and choose “Start Screen Saver” for a corner. Then move the pointer into that corner.
- **Terminal:** Run `open -a ScreenSaverEngine`.

The hot corner is enough if you like to use the mouse. Supercharge is for when you want to start the screen saver from the keyboard.
