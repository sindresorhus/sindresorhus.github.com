@QuickAnswer {
	Open “[System Settings › Desktop & Dock](x-apple.systempreferences:com.apple.Desktop-Settings.extension)”, and choose a browser in “Default web browser”. If you change it often, [Default Browser](../apps/default-browser/index.md) switches it from the menu bar in one click.
}

## With Default Browser

@Steps {
1. Open [Default Browser](../apps/default-browser/index.md), and give it the access that it asks for in [“Device Control and Data Access”](/apps/faq#device-control-access).
1. Click its icon in the menu bar.
1. Choose a browser. It is now the default browser of macOS.
}

A dialog of macOS can show for a moment, but you do not need to click it. To choose the browsers in the menu, or to show the icon of the default browser in the menu bar, open the settings of the app.

@Tips {
- Set a keyboard shortcut for “Toggle menu” in the settings. Then press a number key to choose a browser.
- Hold ++Option++ while you click a browser to open it, without making it the default.
- To switch automatically, like to another browser on the Wi-Fi network of your work, use the “Set Default Browser” action in a Shortcuts automation.
}

To open some links in one browser and other links in another, like Google Meet links in Chrome, you need rules, not a new default browser. [How to open links in a specific browser.](open-links-in-specific-browser-mac.md)

## Without an app

@Steps {
1. Install the browser that you want to use.
1. Open “[System Settings › Desktop & Dock](x-apple.systempreferences:com.apple.Desktop-Settings.extension)”.
1. Scroll down, and choose the browser in “Default web browser”.
}

Most browsers can also make themselves the default browser, with a button in their settings. Then macOS asks if you want to change the default browser or keep the current one. [Apple’s instructions.](https://support.apple.com/102362)

This is fine if you change the browser one time. If you use one browser for work and another for everything else, the menu bar is faster.
