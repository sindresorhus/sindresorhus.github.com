@QuickAnswer {
	Apple does not show the RAM (memory) of an iPhone in Settings or in the specs on its website. The “Get Device Details (Extended)” action of the free [Actions](/actions) app shows it as “Physical Memory”. [Without an app](#without-an-app), find the model name in Settings, and look up the model on a site with specs.
}

## With Actions

@Steps {
1. Install [Actions](/actions), and open it once.
1. In the Shortcuts app, make a new shortcut, and add the [“Get Device Details (Extended)”](/actions#:~:text=Get%20Device%20Details%20%28Extended%29) action of Actions.
1. Add the “Show Content” action. Tap “Device Details” in it, and choose “Physical Memory”.
1. Run the shortcut. It shows the RAM in GB.
}

The number can be a bit lower than the RAM of the model, as a part of the memory is kept for the system. The same action also shows the total and the available storage.

## Without an app

@Steps {
1. Open “Settings › General › About”.
1. Find the model in “Model Name”, like “iPhone 16 Pro”.
1. Search the web for the model and “RAM”.
}

The RAM is the same for all iPhones of one model, so a site with specs of the model is correct, but Apple does not confirm the number.
