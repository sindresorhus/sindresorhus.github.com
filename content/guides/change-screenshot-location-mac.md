@QuickAnswer {
	Press ++Shift+Command+5++, click “Options”, and choose a folder in “Save to”, or “Other Location…”. To change the folder from a shortcut, like a folder for each project, use the “Set Screenshot Location” action of [Shortcutie](../apps/shortcutie/index.md).
}

## With Shortcutie

For a change that you make one time, the Options menu below is enough. A shortcut is better when you change the folder often:

@Steps {
1. Install [Shortcutie](../apps/shortcutie/index.md), and open it once.
1. In the Shortcuts app, click the add button to make a new shortcut.
1. Add the “Set Screenshot Location” action of Shortcutie, and choose the folder.
1. Run the shortcut. The next screenshots go into that folder.
}

To go back to the normal folder, run the action with no folder. The “Get Screenshot Location” action gives the folder that is set now. [Put the shortcuts in the menu bar](add-shortcut-to-menu-bar-mac.md) to change the folder in one click.

## Without an app

The Screenshot app has the setting ([Apple’s instructions](https://support.apple.com/102646)):

@Steps {
1. Press ++Shift+Command+5++.
1. Click “Options”.
1. In “Save to”, choose “Desktop”, “Documents”, or another place, or choose “Other Location…”, and choose a folder.
}

The folder stays the same for all the screenshots that you take after this, also with ++Shift+Command+3++ and ++Shift+Command+4++. To put a screenshot on the clipboard and not in a file, press ++Control++ with the other keys, like ++Control+Shift+Command+4++.

This is free, and all you need if you use one folder. To also have old screenshots moved out of the folder by themselves, see [how to clean up old screenshots](clean-up-old-screenshots-mac.md).
