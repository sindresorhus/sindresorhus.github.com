@QuickAnswer {
	To your own iPhone, use Universal Clipboard: copy on the Mac, and paste on the iPhone. To send the copied text to the iPhone of another person, click the free [Menu Drop](../apps/menu-drop/index.md) in the menu bar, choose “Clipboard”, and choose the iPhone in the AirDrop window.
}

## With Menu Drop

@Steps {
1. Copy the text or the link with ++Command+C++.
1. Click the icon of [Menu Drop](../apps/menu-drop/index.md) in the menu bar, and choose “Clipboard” below “Share From”.
1. Choose the iPhone in the AirDrop window.
}

Menu Drop sends a link as a link. AirDrop cannot send text alone, so Menu Drop sends other text as a text file, “Clipboard.txt”, with the text as plain text. If the clipboard has no text or files, it shows “Clipboard is empty or contains no shareable content.”

@Tips {
- To send the clipboard with one key press, set a keyboard shortcut for “Share from clipboard” in the settings.
- You can also drag selected text or a link to the icon in the menu bar. [How to add AirDrop to the menu bar.](add-airdrop-to-menu-bar-mac.md)
}

## Without an app

Between your own devices, Universal Clipboard is the better way, and you need no AirDrop:

@Steps {
1. Make sure that the Mac and the iPhone are near each other, are signed in with the same Apple Account, and have Bluetooth, Wi-Fi, and Handoff turned on.
1. Copy the text on the Mac.
1. Paste it on the iPhone.
}

[Apple: Use Universal Clipboard](https://support.apple.com/102430)

Universal Clipboard does not work with the iPhone of another person. For that, use AirDrop: in an app that has a Share button, click it, and choose “AirDrop”. Menu Drop is faster, and works with any text that you can copy.
