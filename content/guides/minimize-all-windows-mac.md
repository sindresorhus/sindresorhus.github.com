@QuickAnswer {
	Press ++Option+Command+M++ to minimize all windows of the front app. macOS has no command to minimize the windows of all apps. [Supercharge](../apps/supercharge/index.md) does it from its menu or with a keyboard shortcut, and can also keep the front window open.
}

## With Supercharge

@Steps {
1. Open [Supercharge](../apps/supercharge/index.md), and give it the access that it asks for in [“Device Control and Data Access”](/apps/faq#device-control-access).
1. Click its icon in the menu bar, and choose “Minimize All Windows”. All windows go to the Dock.
1. For a keyboard shortcut, open the Supercharge settings, click “Shortcuts”, and set a shortcut for “Minimize all windows”.
}

“Minimize all windows except frontmost” keeps the window that you use now. “Unminimize all windows” brings the windows back from the Dock. It only minimizes the windows in the current space.

## Without an app

- **Minimize the windows of one app:** Press ++Option+Command+M++, or hold ++Option++ and choose “Window › Minimize All”.
- **Hide all other apps:** Press ++Option+Command+H++. The windows of the front app stay.
- **Show the desktop:** Press ++Fn+F11++, ++Fn+H++, or ++Command++ with the Mission Control key. The windows move to the edges of the screen. Do it again to bring them back.

Hiding and showing the desktop do not put the windows in the Dock. They are good for a quick look at the desktop. Supercharge is for when you want all windows minimized, like before a screen share.
