@QuickAnswer {
	Hold ++Fn++ (or the Globe key) and press a function key to use it the other way one time. To change all of them, macOS has the “Use F1, F2, etc. keys as standard function keys” setting, but no keyboard shortcut for it. In the “Shortcuts” settings of [Supercharge](../apps/supercharge/index.md), set a shortcut for “Function keys” to switch at any time.
}

## With Supercharge

@Steps {
1. Open the settings of [Supercharge](../apps/supercharge/index.md), and click “Shortcuts”.
1. In the “Toggle feature” section, click the field next to “Function keys”, and press the keyboard shortcut that you want.
1. Press the shortcut to switch between the two ways: standard function keys (F1, F2, and so on), or the keys for the brightness, the volume, and the media.
}

This is good when only some of your apps use the function keys, like the debugger of a code editor, or a game. It works only for the built-in keyboard of a MacBook and for the Magic Keyboard.

Supercharge also has a “Set Function Keys Enabled” action for the Shortcuts app, so an automation can change the keys.

## Without an app

- **One key:** Hold ++Fn++ or the Globe key, and press the function key.
- **All keys:** Open “[System Settings › Keyboard](x-apple.systempreferences:com.apple.Keyboard-Settings.extension)”, click “Keyboard Shortcuts…”, click “Function Keys” in the sidebar, and turn on “Use F1, F2, etc. keys as standard function keys”.

[Apple’s instructions.](https://support.apple.com/guide/mac-help/mchlp2596/mac) If you always want the keys the same way, the setting is enough. Supercharge is for when you switch often, as the setting is some clicks deep.
