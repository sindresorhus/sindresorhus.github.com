@QuickAnswer {
	macOS has no keyboard shortcut for True Tone. In the “Shortcuts” settings of [Supercharge](/supercharge), set a shortcut for “True Tone”, and press it to turn True Tone off and on. [Without an app](#without-an-app), open “[System Settings › Displays](x-apple.systempreferences:com.apple.Displays-Settings.extension)”, select the display, and turn off “True Tone”.
}

True Tone changes the colors of the display to match the light around you. Turn it off when you must see the real colors, like when you edit photos or a design.

## With Supercharge

@Steps {
1. Open the settings of [Supercharge](/supercharge), and click “Shortcuts”.
1. In the “Toggle feature” section, click the field next to “True Tone”, and press the keyboard shortcut that you want.
1. Press the shortcut to turn True Tone off. Press it again to turn it on.
}

It works only with a display that supports True Tone. With another display, the Mac only beeps. The menu of Supercharge also has a “True Tone” item. For the warm colors at night, [set a shortcut for Night Shift](guide:night-shift-keyboard-shortcut-mac).

## Without an app

@Steps {
1. Open “[System Settings › Displays](x-apple.systempreferences:com.apple.Displays-Settings.extension)”.
1. If you have more than one display, select the display.
1. Turn “True Tone” on or off. The setting shows only for a display that supports True Tone.
}

[Apple’s instructions.](https://support.apple.com/102147) Some accessibility settings, like invert colors, grayscale, and increased contrast, can turn True Tone off. The setting is enough when you keep True Tone on or off. The shortcut is for when you turn it off for a moment.
