@QuickAnswer {
	In the Files app, touch and hold the text file, tap “Open With”, and choose [Plain Text Editor](/plain-text-editor). You can then read and change the text, and the app saves the changes in the same file. [Without an app](#without-an-app), tap the file in the Files app to see the text in a preview.
}

## With Plain Text Editor

@Steps {
1. In the Files app, find the file, like in the Downloads folder.
1. Touch and hold the file, tap “Open With”, and choose [Plain Text Editor](/plain-text-editor).
1. Read or change the text. The changes save by themselves.
}

You can also open [Plain Text Editor](/plain-text-editor) first, and choose the file in the list of files below “Create Document”. The app opens other text files too, like Markdown (`.md`), CSV, JSON, and log files.

To always open a type of file in Plain Text Editor when you tap it, touch and hold a file of that type in the Files app, tap “Get Info”, and choose the app next to “Always Open With” ([Apple’s instructions](https://support.apple.com/guide/iphone/iphe4bff8827/ios)).

## Without an app

Tap the file in the Files app. When no app is set to open it, the text shows in a preview (Quick Look). To change the text, open the file in an app that edits text, like Plain Text Editor.

To make a new text file, see [how to create a text file on iPhone](guide:create-text-file-iphone).
