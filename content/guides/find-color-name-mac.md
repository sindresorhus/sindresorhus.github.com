@QuickAnswer {
	In [System Color Picker](/system-color-picker), turn on “Show accessibility color name” in the “Advanced” settings. Then press ++Command+P++, and click the color. The window shows its name, like “very dark blue”. [Without an app](#without-an-app), Digital Color Meter shows the values of a color, but not its name.
}

The name is the one that macOS gives a color for VoiceOver, like “very dark blue”. It is useful if you are color blind, or to describe a color in words.

## With System Color Picker

@Steps {
1. Open [System Color Picker](/system-color-picker), and open its settings.
1. Click “Advanced”, and turn on “Show accessibility color name”.
1. In the window, press ++Command+P++, or click the eyedropper button.
1. Click the color anywhere on the screen. The name shows in the window, with the Hex value and the other formats.
}

To pick a color without opening the window first, set a keyboard shortcut for “Pick color” in the “Shortcuts” settings. [How to pick a color from the screen.](guide:pick-color-from-screen-mac)

## Without an app

macOS has no app that shows the name of a color. Digital Color Meter, in the Utilities folder, shows the values of the color below the pointer:

@Steps {
1. Open Digital Color Meter, and choose “View › Display Values › as Hexadecimal”.
1. Move the pointer over the color, and press ++Shift+Command+C++ (“Color › Copy Color as Text”).
1. Search for the Hex value on the web. A color site, like [color-name.com](https://www.color-name.com), shows the nearest name.
}

The names on the web are often fancy, like “Cerulean”. The name in System Color Picker is a plain description, which is easier to understand.
