@QuickAnswer {
	The Contacts app cannot find the blank contacts for you. The “Delete Empty Contacts” action of the free [Actions](../apps/actions/index.md) app deletes all blank contacts at once: the contacts with no name, phone number, email, address, company, or other information. A note does not count.
}

## With Actions

@Steps {
1. Install [Actions](../apps/actions/index.md), and open it once.
1. In the Shortcuts app, make a new shortcut, and add the “Delete Empty Contacts” action.
1. Add the “Show Content” action, and run the shortcut. The first time, allow access to your contacts. The result is the number of deleted contacts.
}

A contact that has only a phone number or an email is not empty, so it stays. A contact that has only a note counts as empty, so it is deleted too. Your own contact card always stays. The contacts are deleted at once, with no question first, so look at your contacts first if you are not sure.

## Without an app

Find each blank contact in the list, and delete it:

@Steps {
1. Open the Contacts app, and tap the contact.
1. Tap “Edit”.
1. Scroll down, tap “Delete Contact”, and tap “Delete Contact” again.
}

[Apple’s instructions.](https://support.apple.com/111793) On a Mac, you can select many contacts in the Contacts app and delete them together. This is fine for a few contacts. Actions is faster when an import or a sync left many blank contacts.
